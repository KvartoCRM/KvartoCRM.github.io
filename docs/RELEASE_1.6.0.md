# KvartoCRM 1.6.0

Adds a workday view, quick tasks and optional next steps after completed calls, meetings and tasks. New tasks retain their contact/property links in history and cross-account backups. Workday hides future dates and preserves the preference per account/device. Existing dashboards and accounting rules are unchanged.

Contact history now combines calls, meeting outcomes, completed linked tasks, notes and messages, with date/type/text filters. The attention panel identifies overdue steps, due next-contact dates and contacts with at least 14 days without communication and no scheduled next step; cold leads are excluded. These are explicit deterministic rules, not AI predictions.

Owner reports use active properties and their assigned owners. Thursday 10:00 Moscow reminder is a weekly task created when Today is opened; completing it creates the next occurrence using the existing recurrence mechanism. A missed reminder remains overdue until completed. Native notifications require notification permission. Report periods default to Thursday 00:00 through the next Thursday 00:00, end exclusive. Only explicitly property-linked history is included. Missing statistics remain unknown. Users can supply current/previous-period facts and up to three screenshots. Saved reports are notes tagged as unsent drafts; there is no automatic delivery. Existing report style can be reused.

DeepSeek integration: note to proposed task/call/meeting, client summary, message draft, owner report and Avito listing. Inputs are visible/editable before the explicit paid request. User confirms every proposed CRM write. Avito requirements come from the supplied document: separate strengths, exactly three distinct titles of at most 30 characters, one copyable listing body and separate clarifications. The property form inserts only the listing body. Up to three manually selected photographs/plans are supported. No browsing/maps are connected; infrastructure is explicitly unverified unless supplied by the user. Images resize locally before upload. No automatic access to files or entire customer database.

Server: separate Cloudflare Worker `kvartocrm-ai`, authenticated through the existing Supabase project; two owner email addresses are allowlisted. DeepSeek and Supabase public client key are Worker secrets. No DeepSeek key is included in source or web assets. Atomic Durable Object quota: 20 attempts per account/day and 100 overall/day, resets UTC. Provider failures after quota reservation also count. Requests are size bounded, provider output validated, redirects not followed, errors redacted. Closing the AI modal cancels the browser request; an already started provider request may still incur usage.

Validation: 148 unit tests + 2 pretests; security/database/gateway/service-worker checks, 9 AI-worker tests, dependency audit, ESLint and production build. Browser fixture tests cover quick task persistence, next-step prompt, contact isolation, report source data and unsent draft persistence, separate Avito output, provider failure preserving input, 320/390/768/1440 widths with enlarged text, workday filtering, history filters and all close controls. New task links and report metadata verified in cross-account restore. Screenshots inspected. No physical phone test and no live customer-record changes.

Live checks: Cloudflare deployment, secret storage, anonymous/invalid-session rejection and a synthetic direct DeepSeek JSON request (56 tokens). Complete logged-in customer-to-Worker-to-provider generation was not exercised with a customer's session during this release. The existing CRM gateway/VPN configuration is unchanged. No SQL migration is required.

# KvartoCRM 1.4.0

Первый этап плана обновления от 28 октября: ежедневная работа с клиентом. Недельная сетка календаря, доска сделок, обратная связь по подборкам и полный файловый архив остаются следующими этапами; этот выпуск не означает завершение всей дорожной карты.

## Изменения

- Исправлена область действия темы в модальных окнах и выпадающих панелях. Поля, подписи, нативные даты и списки соответствуют выбранной теме. Форма события переведена на общие стили.

- Итог звонка и следующий звонок сохраняются одним пакетным запросом к `events`. Идентификаторы сохраняются в черновике; повтор после неопределённого ответа проверяет существующие записи вместо создания дублей.
- Для «Перезвонить» обязательны будущие дата и время. Следующий звонок доступен в «Сегодня», плане звонков календаря и ближайших делах контакта.
- Черновик быстрого звонка восстанавливается на том же устройстве в течение 7 дней. Закрытие предлагает оставить или удалить черновик. Выход из аккаунта очищает новые черновики. Невозможность долговременного сохранения на устройстве обозначается явно.
- «Сегодня» показывает просроченные, сегодняшние, завтрашние, более поздние дела и записи без срока. Из строки можно открыть событие, перенести срок задачи, открыть связанного клиента и записать итог запланированного звонка.
- Завершение запланированного звонка происходит после сохранения итога. Ошибка завершения исходного события сообщается отдельно; повтор не дублирует результат разговора.
- Удалён лимит восьми событий в обзоре. Новый рабочий экран использует постраничную полную загрузку задач и событий.
- Поиск, условия и сортировка запоминаются в контактах, звонках, объектах, задачах, сделках и встречах. В меню фильтров можно сохранить до 12 именованных видов для каждого раздела. Данные привязаны к аккаунту и устройству, синхронизация видов между устройствами в этот выпуск не входит.
- Относительные периоды «Сегодня», «Эта неделя», «Ближайшие 7 дней» пересчитываются. В списках сохраняется позиция прокрутки рабочего контейнера.
- Повторяющаяся задача использует стабильный идентификатор продолжения. Повторное завершение не порождает новую копию. Продолжение создаётся до завершения исходной задачи, чтобы ошибка не скрывала незавершённую операцию. Это последовательность с повтором, а не серверная транзакция двух задач.
- Календарь отделяет будущие звонки от журнала выполненных разговоров. В карточке контакта появились ближайшие открытые события с возможностью изменить срок.

## Проверки

- `npm test`: 125 основных тестов и 2 pretest.
- `npm run test:security`: PGlite, 7 тестов gateway, 2 service worker, production dependency audit.
- Дополнена проверка PGlite: пакет «звонок + следующий контакт» полностью откатывается при чужой связи, корректная пара вставляется вместе, повтор PK отклоняется.
- `npm run lint`, `npm run build`, проверка production network.
- Браузер Edge/Playwright, настоящие компоненты с изолированными HTTP-фикстурами: 11 встреч доступны; черновик восстановлен; ошибка 503 сохраняет ввод; успешный пакет содержит обе записи; повтор с теми же ID не добавляет записи; ближайшее дело и история видны в карточке; повторная задача выдерживает ошибку и цикл done/todo/done; фильтр и именованный вид переживают перезагрузку; мобильная форма 390 px доступна без горизонтальной прокрутки, поля срока заполняются, Escape вызывает защиту черновика. Дополнительно проверены 6 форм (событие, собственник, покупатель, объект, запрос покупателя, объект продавца) во всех 5 темах при ширине 390 px: 30 проверок цветов и отсутствия горизонтальной прокрутки.
- Реальные push-уведомления и физические Windows/Android устройства локально не проверялись. Наличие установленного приложения и разрешений не считается подтверждением доставки уведомлений.

Публикация: штатные workflows GitHub Pages и Windows/Android через тег `app-v1.4.0`. Результат публикации фиксируется после завершения workflows.

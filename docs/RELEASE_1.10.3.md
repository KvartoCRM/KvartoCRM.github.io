# KvartoCRM 1.10.3

Исправлено подтверждение сохранения через «Записать звонок». Каждая запись проверяется отдельным запросом по ID. Отсутствие ответа с записью больше не выдаётся за конфликт с другими данными. Повторное сохранение использует прежний ID и не создаёт дубликат. Сравнение учитывает формат времени PostgreSQL и эквивалентное форматирование JSON заметки.

Если черновик действительно связан с ранее сохранённым звонком с другими данными, форма показывает сохранённую запись для сравнения. Введённый текст сохраняется. Для другого разговора можно явно подготовить отдельную запись, затем сохранить её обычной кнопкой. Существующий звонок не перезаписывается. Для исправления того же разговора остаётся редактирование в журнале звонков.

Проверено: новый звонок, пустое подтверждение и повтор без дубликата, настоящий конфликт и явное создание отдельного звонка с сохранением введённого текста. Серверная миграция не требуется.

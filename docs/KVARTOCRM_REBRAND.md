# Ребрендинг KvartoCRM

Основной сайт: `https://kvartocrm.github.io/`.

Репозиторий и выпуски: `https://github.com/KvartoCRM/KvartoCRM.github.io`.

Публичное название продукта, тексты интерфейса, логотип, иконки, установщики и резервные копии переведены на бренд KvartoCRM начиная с версии 1.3.0.

## Совместимость

Следующие технические идентификаторы временно сохраняют старое имя:

- Android package `com.lumicrm.office`, чтобы версия 1.3.0 устанавливалась поверх прежней без удаления данных;
- Electron `appId`, чтобы обновление Windows не создавало второе приложение;
- Cloudflare Worker и существующие ключи локального хранилища;
- SQL-миграции и имена уже развёрнутых функций Supabase;
- импорт резервных копий старого формата `lumicrm-workspace-backup`.

Их можно переносить отдельно после регистрации собственного домена и подготовки миграции без потери пользовательских данных.

## Визуальная система

- сияние на ключевых действиях и карточках;
- полупрозрачные стеклянные поверхности с размытием фона;
- мягкая неоморфная глубина у панелей и элементов управления;
- интерактивные витрины с бликом и подъёмом при наведении;
- анимированный экран запуска и переходы между разделами;
- поддержка системной настройки уменьшения движения.

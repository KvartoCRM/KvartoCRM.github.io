# KvartoCRM 1.10.4

## Исправления

- «Записать звонок» сохраняет звонок и следующий шаг одной серверной операцией `save_quick_call`, которая возвращает записанные строки. Отдельное чтение для подтверждения больше не требуется. Повтор с теми же ID не создаёт копии. Настоящий конфликт с сохранённым звонком остаётся видимым.
- В форме появилась корзина для очистки текущего черновика с подтверждением. Сохранённые данные аккаунта не очищаются.
- Будущая дата состоявшегося звонка отклоняется с подсказкой использовать следующий шаг.
- В истории можно переместить звонок, итог встречи, выполненную задачу, заметку или сообщение в корзину. Связанное завершённое событие встречи убирается вместе с итогом. Будущие задачи и повторные звонки сохраняются.
- Мия показывает выбранные записи и требует отдельного подтверждения перед удалением. После перезагрузки ожидающее удаление также требует подтверждения. Звонки и итоги встреч удаляются через тот же серверный механизм, что в истории.

## Публикация

До веб-клиента применить миграции `2026112302_quick_call_receipt.sql` и `2026112303_history_trash.sql`. Обновить Cloudflare worker с инструкциями Мии. Сборки приложения: 1.10.4, кэш оболочки: v65.

## Проверки

Автоматические проверки охватывают атомарность сохранения, повтор без копий, изоляцию аккаунтов, запрет анонимных операций, сохранение будущего звонка при удалении истории. Браузерные сценарии проверяют очистку черновика, конфликт, повтор сохранения, подтверждение и отмену удаления, подтверждение Мией после перезагрузки. Проверка серверных функций в рабочей базе проводится в транзакции с откатом, без сохранения тестовых записей.

Расширенные настройки Мии и вложения запланированы отдельно в `MIA_SETTINGS_BACKLOG.md`.

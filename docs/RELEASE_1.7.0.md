# 1.7.0: Мия и архив контактов

- Формы подготовки текстов скрывают служебные JSON-данные. Дополнения вводятся обычным текстом. Рекомендации свёрнуты.
- Чат Мии: приветствие по имени профиля, изменение размера, прокрутка к последним сообщениям при открытии, история на этом устройстве с очисткой при выходе из аккаунта.
- Поиск контактов, объектов, единой истории и задач в аккаунте. Ограниченные выборки обозначены в контексте модели. Данные перечитываются при запросе и перед записью.
- Переходы в разделы CRM, открытие отчётов и истории.
- Запись состоявшегося показа и следующей задачи. Неизвестные ID, архивные контакты, подстановка собственника вместо покупателя, некорректные даты отклоняются. Ближайший понедельник вычисляется относительно московской даты; если сегодня понедельник, берётся следующий.
- Показ и задача сохраняются последовательно. При частичном сбое пользователь видит статус, повтор сохраняет прежние идентификаторы, включая перезагрузку страницы. Уже записанный показ не дублируется. Это не атомарная операция.
- Архивация контакта из карточки, восстановление и доступ к истории из архива. Архивные клиенты исключены из активного списка, подбора покупателей и рекомендаций связаться. Закрытые сделки сами контакты не архивируют.

Ограничения: Мия пока создаёт показы и задачи, но не редактирует сделки, не удаляет записи и не отправляет сообщения клиентам. Поиск истории возвращает до 15 записей за запрос, контактов и объектов до 25. Нет непрерывной передачи кабинета: актуальные данные читаются по запросу. Чат локальный, между устройствами не синхронизируется. Лимит ИИ остаётся 20 запросов в сутки; поиск может потребовать нескольких запросов. Тесты модели на реальных клиентах не проводились.

Проверки: модульные тесты, TypeScript/production build, ESLint, worker auth/quota tests. Браузерные сценарии на синтетических данных: формы без JSON, свёрнутые рекомендации, показ + сбой задачи + перезагрузка + повтор без дубля, открытие отчётов, прокрутка и ширины 320/390/768/1440. Скриншоты мобильных форм просмотрены. Данные реальных клиентов при проверках не изменялись.

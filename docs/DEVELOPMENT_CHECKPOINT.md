# KvartoCRM: точка продолжения

Дата обновления: 5 августа 2026.

## Текущая цель

Превратить личный облачный офис в публичный многопользовательский продукт с регистрацией, синхронизацией, уведомлениями и единым кодом для сайта, ПК, Android и iPhone.

## Стабильная база

- `npm run lint`, `npm run build` и `npm run build:sites` проходят без ошибок.
- Импорт Google Sheets дедуплицирован: повторные звонки и встречи хранятся как история одного контакта/объекта.
- В Supabase сохранены 36 клиентов, 25 объектов, 29 задач, 13 встреч, 68 взаимодействий и 97 исходных строк импорта.
- Приватные документы и фотографии работают через `crm-documents` и `crm-images`.
- Основные запросы ограничены текущим `user_id` поверх RLS.
- Миграции `20260730_crm_foundation.sql` и `20260730_crm_integrity.sql` применены ранее.

## Реализовано 5 августа

- Публичная регистрация по email и паролю с подтверждением адреса.
- Повторная отправка письма, восстановление пароля и маршрут `/auth/callback`.
- Облачный профиль пользователя с темой, размером значков, плотностью интерфейса и положением меню.
- Облачные настройки уведомлений и вводное обучение для нового аккаунта.
- Новая мобильная нижняя навигация.
- «Избранное» и «Архив» переведены со старого локального хранилища на Supabase.
- Объекты можно перемещать в архив и восстанавливать; изменение избранного выполняется оптимистично с обработкой ошибки.
- Все темы используют общие Lumi-токены, включая обучение и новые окна.
- Добавлен центр уведомлений, модель push-подписок и обработчики Web Push в service worker.
- Подготовлена Edge Function `send-push` и миграция `20260805_public_product_foundation.sql`.
- PWA-манифест обновлён для публичного продукта.
- Создан и проверен новый непрозрачный app-icon KvartoCRM; подготовлены размеры 512, 192 и 180 px для PWA/iOS/Android.
- Создан локальный Git-репозиторий и сохранён проверенный фундамент коммитом `a1764b5`.
- Создан публикационный Sites-проект `KvartoCRM`; исходники загружены в его репозиторий.

## Что ещё не активировано в облаке

- Миграция `20260805_public_product_foundation.sql` пока не применена: Supabase SQL Editor перестал отвечать при переходе.
- Email-шаблон и публичные redirect URL Supabase ещё не настроены.
- Для Web Push нужно создать VAPID-пару, добавить публичный ключ в сборку, секреты в Supabase и развернуть `send-push`.
- Публикационная версия Sites не выпущена: загрузка готового архива дважды оборвалась на стороне облачного API. Проект и Git-история сохранены, создавать их повторно нельзя.

## Следующий безопасный порядок

1. Повторно открыть Supabase и применить `20260805_public_product_foundation.sql`.
2. Включить email confirmation, настроить письмо KvartoCRM и redirect URL опубликованного домена.
3. Выпустить уже созданную Sites-версию и включить публичный доступ.
4. Проверить регистрацию новым тестовым адресом, письмо, onboarding, настройки, избранное и архив.
5. Активировать Web Push и центр уведомлений.
6. Подключить Capacitor 8 для Android/iPhone; iOS-сборку и подпись выполнять на macOS/Xcode.
7. После стабилизации веб/PWA подготовить установщик ПК (PWA как базовый вариант, Tauri 2 — для нативного установщика после установки Rust/C++ Build Tools).

## Публикация

- `.openai/hosting.json` содержит ID уже созданного Sites-проекта.
- `sites/worker.mjs` обеспечивает SPA fallback для прямого открытия внутренних маршрутов.
- `npm run build:sites` формирует Cloudflare-совместимый worker в `dist/server/index.js`.
- Архив готовой версии хранится локально в `tmp/lumicrm-sites.tar.gz` и не входит в Git.
- `.env` и ключи Supabase исключены из Git; в репозитории есть только безопасный `.env.example`.

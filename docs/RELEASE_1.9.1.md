# KvartoCRM 1.9.1

Мия: Enter отправляет сообщение, Shift+Enter переносит строку. Сохраняется кнопка отправки. Кнопка открытия скрывается при открытом чате; чат располагается выше шапки. Добавлены отступы кнопок памяти, контактов и форм; панель сохранения события больше не перекрывает заметки.

Убрана дневная квота приложения для всех режимов ИИ. Технические ограничения размера запроса, времени ответа, доступа к своему аккаунту и проверки действий сохраняются. Доступность зависит от баланса и ограничений DeepSeek и Cloudflare.

Для Мии включён режим рассуждения DeepSeek. Контекст расширен: до 20 последних реплик и обзор всех собственников, включая архив, связанные объекты, завершённые сделки и последние записи общения. При превышении размера контекста выборка явно помечается как частичная; подробности доступны через поиск с пагинацией. Проверка формата действий с двумя попытками исправления выполняется до записи в CRM. Благодарности и смайлики не выполняют команды.

Долговременные уточнения о клиентах и предпочтениях могут сохраняться без слова «Запомни». Модель отмечает нужную реплику, сервер сохраняет только исходное сообщение пользователя в облаке его аккаунта. Запись видна в «Памяти», её можно удалить. Отключённая память запрещает такое сохранение. Выбор реплики моделью не гарантирован; явная команда «Запомни» остаётся доступна.

Проверки: модульные тесты, Worker и облачный журнал, безопасность, lint, сборка. Браузерные сценарии на синтетических данных: Enter/Shift+Enter; неверная команда и её исправление без дубля задачи; смайлик без API-запроса; архивный собственник; сохранение уточнения, перезагрузка и использование памяти; удаление факта; два устройства и восстановление после сбоя. Ширины 320/390/768/1440. Реальные записи клиентов при проверках не изменялись. Качество ответов живой модели отдельно не оценивалось.
